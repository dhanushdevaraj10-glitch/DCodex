Module 2 — Keywords, Variables & Identifiers

Reserved words · Data storage · Naming rules

▼

🔑 Keywords

Keywords are reserved words in a programming language. They have a fixed meaning and cannot be used as names.

Examples: if else for while break continue class def return
if = 10  # ❌ Error — 'if' is a keyword

📦 Variables

A variable is a name used to store data in memory. The value can change.

age = 25
name = "Naveen"
# age, name → variables
# 25, "Naveen" → values

🏷️ Identifiers

Identifiers are names given to variables, functions, classes, and objects.

total_marks = 450  # total_marks is an identifier

Module 6 — Slicing in Python

String · List · Tuple · Set · Dict · Range · Bytes

▼

📐 Slicing Syntax

sequence[start : end : step]
# start → begin (included)
# end   → stop  (excluded)
# step  → jump size

📝 String Slicing

s = "PYTHON"
print(s[0])     # 'P'
print(s[1:4])   # 'YTH'
print(s[:3])    # 'PYT'
print(s[3:])    # 'HON'
print(s[-1])    # 'N'
print(s[::-1])  # 'NOHTYP' (reverse)
Strings are immutable — cannot change characters after creation.

📋 List Slicing (Mutable)

l = [10, 20, 30, 40, 50]
print(l[1:4])   # [20, 30, 40]
print(l[::-1])  # [50, 40, 30, 20, 10]
l[0] = 99       # Allowed — list is mutable

📦 Tuple Slicing (Immutable)

t = (1, 2, 3, 4, 5)
print(t[1:4])   # (2, 3, 4)
print(t[::-1])  # (5, 4, 3, 2, 1)
# t[0] = 100   # ❌ Error — immutable

🚫 Set & Dict — No Slicing!

s = {1, 2, 3}
# s[0]    # ❌ TypeError — unordered
lst = list(s)
print(lst[1:3])  # Workaround

d = {"a": 1, "b": 2, "c": 3}
keys = list(d.keys())
print(keys[:2])  # ['a', 'b']

Module 8 — Loops in Python

for loop · while loop · break · continue · pass

▼

🔁 for Loop

Used to iterate over a sequence. Handles initialization, condition checking, and incrementing automatically.

# Print 1 to 5
for i in range(1, 6):
    print(i)

# Loop through a list
fruits = ["apple", "banana", "mango"]
for f in fruits:
    print(f)

🔂 while Loop

Repeats as long as condition is True.

# Print 1 to 5
i = 1
while i <= 5:
    print(i)
    i += 1

# Sum of first 5 numbers
i, total = 1, 0
while i <= 5:
    total += i
    i += 1
print("Sum =", total)  # Sum = 15

# Reverse a number
num, rev = 1234, 0
while num > 0:
    digit = num % 10
    rev = rev * 10 + digit
    num //= 10
print("Reversed =", rev)  # 4321

🛑 Loop Control Statements

StatementDescriptionExample
breakStops the loop immediatelyif i == 3: break
continueSkips current iterationif i == 3: continue
passDoes nothing (placeholder)pass
for i in range(1, 6):
    if i == 3:
        continue  # skip 3
    if i == 5:
        break     # stop at 5
    print(i)
# Output: 1 2 4

📦 Tuple Creation

# Unpacking

Module 16 — Comprehensions

Module 17 — Modules & Packages

Built-in · User-defined · External · Package structure

▼

📄 What is a Module?

A module is a single Python file (.py) containing functions, variables, and classes. Every .py file = one module.

# math_tools.py
def add(a, b): return a + b
def subtract(a, b): return a - b

# main.py
import math_tools
print(math_tools.add(10, 5))       # 15
print(math_tools.subtract(10, 5))  # 5

🏷️ Types of Modules

TypeExamples
Built-inmath, random, datetime, os, sys
User-definedYour own .py files
External (pip)numpy, pandas, matplotlib
import math
print(math.sqrt(16))  # 4.0

# Install external
# pip install numpy
import numpy as np
print(np.array([1,2,3]))

📁 What is a Package?

A package is a folder containing multiple modules with an __init__.py file.

math_package/
├── __init__.py   ← makes it a package
├── add.py
└── sub.py

# add.py
def add(a, b): return a + b

# main.py
from math_package.add import add
print(add(10, 5))  # 15

📊 Module vs Package

TermMeaning
ModuleA single .py file
PackageA folder with multiple modules

class Student:

self refers to the current object. Without it, Python doesn't know which object's data we're accessing.

class BankAccount:
    def __init__(self, balance):
        self.__balance = balance  # private

🎭 Abstraction (ABC)

from abc import ABC, abstractmethod

class PaymentGateway(ABC):
    @abstractmethod
    def pay(self, amount):
        pass

class GooglePay(PaymentGateway):
    def pay(self, amount):
        print(f"Paid ₹{amount} using Google Pay")

class PhonePe(PaymentGateway):
    def pay(self, amount):
        print(f"Paid ₹{amount} using PhonePe")

def process(p): p.pay(500)
process(GooglePay())  # Paid ₹500 using Google Pay
process(PhonePe())    # Paid ₹500 using PhonePe

⚡ Generators

def count_up_to(n):
    count = 1
    while count <= n:
        yield count   # pauses and returns value
        count += 1

for num in count_up_to(5):
    print(num)   # 1 2 3 4 5

# Using next()
gen = count_up_to(3)
print(next(gen))  # 1
print(next(gen))  # 2
