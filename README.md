# DCodex - Learn Python by Doing

Welcome to **DCodex**, a premium, interactive educational web platform designed to help students learn Python through hands-on projects! 

## Features

- **Multi-Page Layout**: Clean and modular structure featuring Home, Projects, Run Code, and Contact pages.
- **In-Browser Python Execution**: Powered by Pyodide, Python code runs directly in the browser. No backend server is required! 
- **Monaco Code Editor**: Integrated with the same powerful code editor engine that powers VS Code for a realistic development experience.
- **Interactive Prompts**: Specially patched `input()` support allows interactive text-based Python games to be played natively within the browser environment.
- **Projects Showcase**: Explore 5 pre-loaded Python projects (Rock Paper Scissors, Quiz Game, Number Guesser, Choose Your Adventure, Roll Dice).
- **Contact Form Integration**: Fully functional contact form powered by FormSubmit.

## Getting Started

To run this project locally, simply start the development server using Vite:

```bash
cd codex-web
npm install
npm run dev
```

Then navigate to `http://localhost:5173` in your browser.

## Technologies Used
- HTML5 / CSS3 (Vanilla)
- JavaScript (ES6 Modules)
- [Vite](https://vitejs.dev/) - Frontend Tooling
- [Pyodide](https://pyodide.org/) - WebAssembly Python Runtime
- [Monaco Editor](https://microsoft.github.io/monaco-editor/) - Code Editor
- [Streamlit](https://streamlit.io/) - (Includes legacy Python-only app in root folder)
